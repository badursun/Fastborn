Erase modes

Two modes. One choice.

GRUB waits three seconds. Touch nothing and Quick mode starts; pick Full for sensitive data.

DEFAULT

> Quick

~15–20 min for an 80 GB disk

  • Starts automatically after the 3-second GRUB timeout

  • Clears boot-sector malware along with the data

Install

Write it to USB.

One ~20 MB ISO, runs entirely from RAM and never touches the target disks while booting. The boot stick itself is excluded automatically (removable=1).

01Download Rufus (portable, no install)
02Plug in the USB stick and select it as Device
03Boot selection → fastborn.iso
04Partition scheme MBR · target BIOS or UEFI
05START → choose DD Image mode → OK
altbalenaEtcher: Flash from file → select target → Flash!
01diskutil list# find the USB disk number
02diskutil unmountDisk /dev/diskX
03sudo dd if=fastborn.iso of=/dev/rdiskX bs=1m status=progress
04diskutil eject /dev/diskX
01lsblk# find the USB device
02sudo dd if=fastborn.iso of=/dev/sdX bs=1M status=progress conv=fsync

V2 · in development

Next: evidence you can sign.

V2 rebuilds FastBorn around fail-closed safety and verifiable evidence: native sanitize commands, full readback, parallel coordination and cryptographically signed sanitization certificates.

V2 is not a qualified release yet. Normal V2 images ship without an arming document and deliberately stop before any erase command; destructive engines run only in guarded QEMU lab images. Download v1.0 for real use today.

IRREVERSIBLE. THERE IS NO UNDO.

FastBorn is built to destroy data. Treat the stick like a loaded tool.

  • All internal disks are wiped on boot — auto mode has no confirmation prompt
  • Do not plug it into the wrong machine — you will lose everything
  • Boot USB is auto-excluded via removable=1 detection — still verify your setup
  • 5-second window before erasure starts — Ctrl+C aborts
Build from source

Reproducible, in Docker.

terminal
